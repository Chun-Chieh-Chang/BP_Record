# BP Record (血壓 Nexus)

專業居家血壓量測與追蹤系統，遵循 722 原則與醫療標準，具備全日九量與趨勢分析功能。

## 🌟 核心功能
- **722 原則實作**：標準化居家量測流程。
- **全日九量模式**：早、中、晚各三量，全面監控血壓波動。
- **智慧平均算法**：自動捨棄單回最高值，排除偶發離群數據。
- **視覺化分析**：專業工程風格圖表，自動標註健康區間與異常紅點。
- **多人管理**：支援家庭成員數據隔離與永久儲存。
- **PWA 支援**：可安裝至手機主畫面，離線亦可查看指引。
- **資料匯出匯入**：支援 Excel 報表與 JSON 雲端備份。

## 📁 專案結構 (MECE)
- `server.js`: 高效能 Node.js 後端服務與 API。
- `index.html`: 智慧三欄式前端控制台。
- `assets/`: 靜態資源（Chart.js、PWA 清單、圖示）。
- `wiki/`: 醫療知識庫與量測指引。
- `DEV_LOG.md`: 基於 PDCA 的開發記錄。

## 🚀 快速啟動
1. 安裝依賴：`npm install`
2. 啟動伺服器：`node server.js`
3. 訪問：`http://localhost:3000`
